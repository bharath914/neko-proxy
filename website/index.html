Run Neko

Open the app. It starts the proxy on port 8899 and listens for traffic.

Point your device at it

Browser, phone or terminal: set the proxy to your computer's address. Phones can pair by QR code.

Try it from source

Needs only Rust (rustup.rs).

git clone https://github.com/bharath914/proxy.git
cd proxy
cargo run --release -p neko-desktop

On a Mac: cargo build -p neko-cli && cd desktop-macos && swift run Neko. Installers are on the releases page.
